# Security Policy

## Project Scope

This repository is a GitHub Skills practice project using the fictional Mergington High example. It is not intended for production use or real student data. There are no supported production releases or guaranteed response times.

## Reporting a Vulnerability

Please do not disclose vulnerabilities in public issues, pull requests, or discussions.

1. Open this repository's **Security** tab and use **Report a vulnerability**, if private vulnerability reporting is enabled.
2. Describe the issue, affected files or versions, reproduction steps using fictional data, potential impact, and any suggested fix.
3. Never include passwords, tokens, real student information, or other unnecessary personal information.
4. If the private reporting option is unavailable, ask @tsuchiyang to enable it without sharing vulnerability details publicly. Wait for a private reporting channel before sending details.

The maintainer can assess reports and coordinate a fix privately. Please avoid public disclosure while a report is being assessed. No acknowledgement or resolution deadline is promised for this learning repository.

## Development Precautions

Use only local sample data. Do not deploy the tutorial's sample accounts or configuration as a production service. Review dependency and code-scanning findings when those tools are enabled.
