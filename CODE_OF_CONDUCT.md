# Code of Conduct

## Our Pledge

We welcome contributors to this GitHub Skills practice project and aim for a respectful, harassment-free experience for everyone. Mergington High is a fictional school used by the exercise.

## Our Standards

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Accept constructive feedback and focus on improving the project.
- Show empathy and keep discussion relevant.

Harassment, threats, discriminatory language, personal attacks, trolling, and publishing another person's private information without permission are unacceptable. Never include real student information in this practice repository.

## Responsibilities and Scope

Maintainers may remove or reject contributions that violate these standards and may restrict participation for serious or repeated violations. Decisions should be fair and proportionate. These expectations apply in repository issues, pull requests, and other spaces where someone represents this project.

## Reporting and Enforcement

For abusive content on GitHub, use the content's **Report content** option or GitHub's reporting process. Do not reproduce private information in public reports. For an ordinary moderation concern that contains no sensitive details, notify the repository owner, @tsuchiyang, in the relevant discussion. This practice repository does not publish a separate private moderation contact.

Maintainers should review concerns fairly, consider their context, and apply proportionate corrective action, such as requesting a correction, removing content, or restricting participation. No response-time guarantee is offered.
